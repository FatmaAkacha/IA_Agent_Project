# 🤖 IA Agent Project

Un agent intelligent développé en Python capable d'analyser les questions des utilisateurs et d'exécuter différentes actions selon leur intention.

## 📌 Fonctionnalités

- 💬 Analyse des questions utilisateur
- ➕ Calculatrice intégrée
- 📄 Lecture de fichiers TXT
- 📕 Lecture de fichiers PDF
- 📘 Lecture de fichiers DOCX
- 🔀 Routage automatique des requêtes avec LangGraph
- 🧠 Gestion d'un historique de conversation (mémoire)
- ⏱️ Mesure du temps de réponse

## 🛠️ Technologies utilisées

- Python 3
- LangGraph
- PyPDF
- python-docx

## ⚙️ Installation

### 1. Cloner le projet

```bash
git clone https://github.com/FatmaAkacha/IA_Agent_Project.git
```

### 2. Accéder au dossier

```bash
cd IA_Agent_Project
```

## ▶️ Exécution

Lancer le programme :

```bash
python agent.py
```

## 🧠 Fonctionnement

L'application suit les étapes suivantes :

1. Réception de la question utilisateur.
2. Analyse de l'intention.
3. Sélection du traitement approprié :
   - Calcul
   - Lecture TXT
   - Lecture PDF
   - Lecture DOCX
4. Génération de la réponse.
5. Ajout à l'historique de conversation.
